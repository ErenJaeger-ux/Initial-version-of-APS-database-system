\# База данных АПС (локальная intranet-версия)



Локальное веб-приложение для учета и анализа срабатываний АПС  

(предназначено для использования внутри одной сети / на одном ПК).



\## Назначение

Приложение используется для:

\- ведения журнала выездов по срабатываниям АПС;

\- анализа повторных выездов;

\- формирования отчетов (по кварталам и по месяцам);

\- удобного поиска и сортировки записей.



Работает \*\*без сервера и без интернета\*\* — все данные хранятся локально в браузере.



\## Основные возможности

\- Журнал записей (дата, время, адрес, объект, ключ)

\- Быстрый поиск по адресу / объекту / ключу

\- Сортировка по столбцам

\- Отчеты:

&nbsp; - все выезды по кварталам

&nbsp; - 3 и более выезда \*\*за месяц\*\*

\- Управление справочниками:

&nbsp; - адреса и объекты

&nbsp; - автозаполнение при вводе (аналог T9)

&nbsp; - редактирование и удаление

\- Экспорт и импорт базы (JSON)



\## Технологии

\- HTML + CSS + JavaScript

\- LocalStorage (локальное хранение данных)

\- Без серверной части



\## Запуск

1\. Склонировать репозиторий или скачать файл

2\. Открыть `data\_base\_aps.html` в браузере (Chrome / Edge)

3\. Можно использовать сразу
