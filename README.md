# База данных по сработкам АПС (локальная intranet-версия)

Локальное веб‑приложение для учёта выездов/сработок АПС с хранением в SQLite на одном офисном ПК.

## Возможности (v1)
- Журнал всех записей (дата, время, ключ, адрес, объект)
- Поля по ложному выезду:
  - Ложный выезд (да/нет)
  - Требуется возмещение (да/нет)
  - Письмо направлено (да/нет)
  - Примечание
- Быстрый поиск (адрес/объект/ключ)
- Сортировка по столбцам (клик по заголовку)
- Группировка по объектам (раскрытие «все выезды по объекту»)
- Анализ по кварталам (3+ выездов на объект за квартал)
- Экспорт/импорт JSON

## Установка (Windows)
1) Установи Python 3.10+  
2) Открой терминал в папке проекта и выполни:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открой в браузере: `http://127.0.0.1:5000`

## Доступ по локальной сети
Приложение слушает `0.0.0.0:5000` (видно в сети).  
На ПК‑сервере открой порт 5000 в брандмауэре Windows (входящие TCP).

## Где лежит база
Файл БД: `data/aps.db` (исключён из git через `.gitignore`).
