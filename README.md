# APS Database System

Локальная HTML-система учёта сработок АПС с витриной просмотра.

## Назначение
Проект предназначен для внутреннего использования:
- ведение базы выездов АПС
- просмотр данных через HTML-витрину
- экспорт данных в общую сетевую папку (read-only)

## Архитектура
- Основная рабочая версия — локально на ПК диспетчера  
- Витрина — HTML-страница для просмотра без прав редактирования  
- Обновление витрины — вручную по необходимости
